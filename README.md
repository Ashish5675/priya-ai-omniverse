## 🧠 Overview

Priya AI Omniverse is an intelligent AI-based assistant designed to perform real-world tasks using voice commands, face recognition, and automation systems.

This project focuses on building a **multi-agent AI ecosystem** capable of interacting with humans and controlling smart environments.

---

## 🎯 Key Features

* 🎤 Voice Recognition System
* 👁️ Face Detection & Identification
* 🤖 Multi-Agent Task Execution
* 🏠 Smart Home Automation Integration
* 🧠 AI-Based Decision Making
